# Note corrections — draft set

Proposed rewrites for all 188 Group 1 findings in [findings-worklist.md](../findings-worklist.md)
(factual errors in translator's notes). Each entry quotes the current footnote verbatim from
`translation/book-NN.md` (with its line number), proposes a full replacement note, and gives a
one-line rationale sourced from the batch adjudication. **Status: all 188 corrections were applied
to the translation files on 2026-08-05** (verified: each Current line matched uniquely before
replacement; `git diff` showed exactly 188 changed lines across 23 files). The "Current" blocks
below preserve the pre-correction text as the historical record.

Editorial principles used throughout:

- Fix the false claim; keep the note's voice, structure, and length.
- Where a wrong superlative ("only," "first," "every," "verbatim") carried the note's argument,
  replace it with the accurate observation rather than merely deleting — in most cases the true
  version turned out to be the stronger point.
- Invented precision (ages, headcounts, distances, clock-times) is removed, not re-estimated,
  unless the poem supplies a real number.
- Wrong line-interval counts are corrected against the cited line numbers.
- Where a note quotes verse that is itself under a Group 3 policy decision (δαιμόνιε renderings,
  etc.), the entry flags the dependency instead of preempting the decision.
